# 工作台（Workbench）

个人效率工作台 — Windows 桌面版。Electron + React + Ant Design + SQLite（sql.js，纯 JS 无需编译环境）。五个阶段全部完成。

## 当前功能（阶段 5 · 全量）

- **快速搜索面板**（`Alt+Q`，可自定义）：聚光灯式全局面板，一个输入框同时搜索任务 / 便签 / 启动项 / 剪贴板历史，↑↓ 选择、Enter 执行、Esc 关闭；支持「新建任务：xxx」命令直接建任务
- **剪贴板历史**：自动记录复制过的文本与截图（仅存本机），搜索、一键复制回贴、置顶收藏、删除/清空；自动清理（非置顶保留最近 500 条 / 7 天）；可随时暂停自动记录；双击条目即复制
- **AI 助手**（OpenAI 兼容接口：DeepSeek / 通义千问 / Kimi / OpenAI / 本地 Ollama 均可）
  - 对话流式输出，历史持久化，可随时停止/清空
  - **AI 可直接操作工作台**（工具调用）：查询/创建/更新任务（状态、日期、进度）、查询统计、新建桌面便签；对话里说「新建任务：明天下午写周报，很重要」即可自动换算日期并建任务
  - API Key 使用 Windows 系统凭据加密存储，不出本机
- **自动报告**：周报 / 月报 / 年报（本期/上期），读取区间内任务完成、项目分布、逾期、专注数据；配置 AI 后自动撰写叙述总结，未配置时输出纯统计版；历史存档、复制、导出 .md
- **系统托盘**：关闭主窗口即最小化到托盘（不退出），托盘菜单：主窗口 / 快速搜索 / 小组件 / 便签 / 退出
- **屏幕边缘停靠**：把主窗口拖到屏幕左 / 右 / 上边缘松手，窗口会以神灯动效「收」成一枚贴边小拉手（透明窗口，圆角 + 呼吸辉光）
  - 悬停约 0.3 秒（或直接点击）→ 沿边滑出图标栏，12 个功能入口都在
  - 点图标 → 图标栏原地展开成面板（图标列 64px + 内容区 800px），不打断当前上下文
  - 栏底「展开」或再次点把手 → 回到完整窗口并退出停靠
  - 拉手与图标栏顶部抓手都可按住沿边缘拖动，位置自动记忆；鼠标离开约 0.75 秒自动收回
  - 设置页可整体关闭停靠（`edgeDock`）
- **全局热键**（任何界面生效，可在设置中自定义）：
  - `Alt+Space` 显示 / 隐藏主窗口
  - `Alt+Q` 快速搜索面板
  - `Alt+W` 显示 / 隐藏桌面小组件
  - `Alt+N` 新建便签
  - `Alt+L` 呼出「快捷启动」桌面小组件
- **桌面小组件**：半透明深色小面板悬浮桌面，含今日待办（可勾选完成）、快速添加、本周完成 / 逾期 / 今日专注迷你统计；位置自动记忆，30 秒自动刷新
  - **外观可调**（设置 → 桌面小组件）：9 个预设背景色 + 任意取色、背景不透明度 0~100%，改完即时生效不用重开窗口
  - 文字与分隔线颜色按背景亮度**自动切换深浅**，选浅色背景也不会看不清；背景很透时自动加重描边并给文字加一层深色阴影兜底
  - 「启动项小组件（`Alt+L`）」与「任务小组件（`Alt+W`）」共用同一套外观
- **桌面便签**：多张便签钉在桌面（置顶无边框），4 色可换，内容自动保存，拖动位置记忆，关窗口=隐藏不删除；启动时自动恢复所有便签；设置页可管理（新建 / 打开 / 删除）
- **快捷启动**：卡片墙管理常用文件夹 / 网页 / 软件，双击或点「打开」直达
- **总览看板**：今日待办 / 已逾期 / 本周完成 / 今日专注四张卡片，最近 14 天趋势图，今日待办、逾期、最近完成清单，可勾选完成
- **任务管理**：新建 / 编辑 / 删除，状态流转（待办 → 进行中 → 已完成 / 挂起 / 已取消），项目、标签、进度、预估番茄数、开始 / 截止日期，逾期高亮，搜索与筛选
- **四象限视图**：重要 × 紧急两轴，拖拽卡片跨象限自动调整属性，按象限快速添加
- **日历**：月视图 + 周视图，按截止日展示，勾选完成，点日期快速新建
- **甘特图**：按项目分组可折叠，按日 / 周 / 月缩放且时间轴始终占满宽度；拖动任务条整体调期，拖动两端改起止，条内浅色填充为进度
- **番茄钟**：专注 / 短休 / 长休自动循环（时长与轮数可配置），可绑定任务，完成后系统通知；页面常驻后台，切走计时不断；今日 / 本周统计 + 14 天柱状图 + 最近记录
- **深色模式**：侧边栏开关一键切换，偏好持久化
- **数据备份**：备份目录可指向 NAS 映射盘 / UNC 路径；支持立即备份、每天自动备份、保留最近 10 份、一键恢复（恢复后自动重启）
- **导入导出**：固定 xlsx 模板（含填写说明 sheet），导入前预览 + 逐行校验，追加 / 覆盖两种模式；导出与模板同列可回导
- **本地存储**：SQLite 单文件，位于 `%APPDATA%\工作台\workbench.sqlite`，所有变更自动落盘

## 环境要求

- Node.js ≥ 18（本机未装 Node 时，可用工作区 `tools/` 下的便携版，见下）
- npm（随 Node 附带）

## 常用命令

```bash
npm install        # 安装依赖（首次）
npm run dev        # 开发模式（Vite 热更新 + Electron）
npm run build      # 构建（主进程 tsc + 渲染层 vite）
npm start          # 运行已构建版本
npm run smoke      # 冒烟测试（无窗口后台启动，输出 SMOKE_OK 即通过）
npm run dist       # 打包 Windows 安装包（electron-builder → NSIS）
```

冒烟测试可用环境变量指定抓取目标（截图落在 `.smoke/`）：

```bash
set "WORKBENCH_SHOT=6"      # 1 任务 / 2 四象限 / 3 日历 / 4 甘特 / 5 番茄钟 / 6 总览 / 7 设置
                            # 8 小组件 / 9 便签 / 10 启动 / 11 AI / 12 报告 / 13 剪贴板
                            # 14 搜索 / 15 便签管理 / 16 边缘停靠（拉手·图标栏·面板）
                            # 21 启动项小组件 / 22 收缩把手 / 23 顶部停靠
                            # 24-26 透明窗口白边回归（真机截屏）：24 启动项小组件 / 25 任务小组件 / 26 便签
                            # 27 小组件外观回归：背景色 / 不透明度 / 文字自动反差（真机截屏 + 像素断言）
                            # 28 报告页交互回归：真实鼠标事件点「周报/月报/年报」→ 选中项 + 区间提示 + 落库 kind
                            # 29 报告生成计时探针：逐档打印耗时（排查「点了没反应 / 只出周报」）
                            # 30 报告链路自包含回归：本地假 AI 服务器，验证单轮无工具、不污染 ai_messages、挂住会超时退化
set "WORKBENCH_DOCK_HOLD=1"        # 仅 SHOT=16：钉住展开态（否则鼠标不在上面会自动收回，截不到）
set "WORKBENCH_DOCK_FRAC=1"        # 仅 SHOT=16：强制把手停靠位置（0~1，沿边缘比例），用于验证贴边边界几何
set "WORKBENCH_DATA_DIR=D:\tmp\wb" # 把数据目录指到别处：冒烟跑在隔离库上，不污染真实数据，也不会和正在运行的应用抢单实例锁
set "WORKBENCH_REPORT_AI_TIMEOUT_MS=5000"  # 仅测试用：缩短报告 AI 叙述的超时，快速验证「挂住→退化」分支
set "WORKBENCH_DARK=1"             # 深色模式
set "WORKBENCH_SHOT_PREFIX=dark-"  # 截图文件名前缀，便于浅色/深色各存一份
```

本机没有全局 Node 时，先把它加进当前终端的 PATH：

```bat
set "PATH=<你的便携 Node 目录>\node-v22.14.0-win-x64;%PATH%"
```

## 镜像加速

项目根目录 `.npmrc` 已配置 npmmirror（npm 包 + Electron 二进制），国内网络可直接 `npm install`。

## 数据与备份

- 数据库：`%APPDATA%\工作台\workbench.sqlite`（可在应用侧边栏点「打开数据文件夹」直达）
- 备份：复制该文件即可；后续版本会加自动备份到 NAS 共享目录
